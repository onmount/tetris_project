Чтобы запустить проект нужно сложить все файлы в одну директорию и запустить main.py

Проект должен показать игру, где тетрамино по одному падают с неба пока не упрутся в землю. Когда появляются пути по белым линиям, соединяющие стороны поля, произвольный путь среди них удаляется, клетки осыпаются вниз. Этот процесс повторяется пока пути остаются. За каждую удаленную клетку игрок получает 10 очков. Пользователю показывается следующее к появлению тетрамино. Игра заканчивается, когда негде появиться новому тетрамино.
